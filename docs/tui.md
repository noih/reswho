# 基本 TUI

stdin 與 stdout 都是 TTY 時，`reswho` 自動開啟 TUI；其他情況預設一次性 Markdown。`--tui` 要求終端機，`--md`／`--json` 明確指定一次性輸出。

沿用既有 snapshot、分類與容器 adapter，不另作名稱猜測。`--from` 選擇根節點，`--depth` 控制初始展開深度，之後仍可手動往下展開。`--sort cpu|memory|uptime|name` 設定初始排序（預設 memory），與 Markdown／JSON 共用比較規則。

全機視圖直接從分類開始，不顯示重複的 Resources 根列；整機用量與程序數保留在頂端。全機 `--depth 0`／`1` 仍顯示收合的分類，預設 `2` 展開到其下一層。System 若只有一個 System services 包裝，則直接顯示其執行檔群組／程序。這只改變 TUI 呈現，snapshot、Markdown／JSON 與原有 group ref 均保留；明確 `--from` 指定的其他根節點仍顯示。

| 按鍵 | 操作 |
| --- | --- |
| ↑／↓、k／j | 選取上一／下一列 |
| ←／h、→／l | 收合或父層、展開或子層 |
| Enter／Space | 展開／收合 |
| Home／End、PgUp／PgDn | 首尾列、移動十列 |
| c／m／u | 同層 CPU／RAM／uptime 降序排列 |
| n | 同層名稱自然升序排列 |
| / | 搜尋名稱、PID、ref、路徑；Enter 保留，Esc 清除 |
| a | 容器 all／active 切換；保留未知狀態 |
| [／] | 左右捲動底部路徑列 |
| r／p | 立即刷新／暫停自動刷新 |
| ?、q／Ctrl-C | 說明、退出 |

搜尋保留匹配項目的父層；匹配群組時顯示其子樹。清除搜尋會恢復原展開狀態。篩選只影響顯示，不重算 totals；容器與主機資源維持不同計算範圍。Age 是程序啟動至今的時間，群組為最老成員，並非持續忙碌時間。`?` 表示未知，`-` 表示不適用，`>=` 表示部分已知值。

名稱排序忽略大小寫，連續ASCII數字比較完整數值，因此 `1, 2, 3, 10, 11`、`node2, node10`、`v2.3, v2.11` 依自然順序排列。相同數字片段的短寫法先，例如 `2` 在 `02` 前；不以固定寬度整數解析，長數字不溢位。相同名稱以 ref 穩定排序，不改父子層級，切換排序與刷新都保留選取。

排序、刷新或篩選重排列項目時，若原選取身分仍存在，捲動位置會盡量讓它留在畫面原本那一列；靠近列表邊界或視窗變小時，以保持選取可見為優先。一般上下移動不鎖定畫面列，Home／End 仍可跳到首尾。原項目消失時退到仍可見的父層；沒有可用父層才選第一列，空結果則不選取任何列。

數值依列上口徑降序排序：程序用自身用量，群組用所屬範圍合計，部分合計使用已知下界；全未知／不適用置後。同值以 ref 穩定排序。程序列不以子樹合計取代自身用量。

頂端 `Host CPU` 為整機0–100%用量；表格 `CPU/core` 以單一核心100%計算，程序與群組可以超過100%。`>=` 表示部分成員不可讀，顯示的是已知用量下界，不能直接與整機CPU百分比相比。

資源樹使用完整寬度，底部 status bar 顯示選取程序的 cwd／exe，或 app／專案／bin 的已知路徑；容器保留 project、candidate、bind 的來源標籤。沒有路徑時顯示 `Path —`，不從名稱猜測。長路徑可用 `[`／`]` 捲動，切換選取時回到開頭。錯誤仍在底部提示；完整資料可用 `--md --from REF` 或 `--json --from REF` 查詢。

列表名稱不重複附加 `[app]`／`[bin]` 等分類標記；選取後在底部狀態列顯示 `app · group:…`，有錯誤時優先顯示診斷。程序仍保留 PID，Markdown／JSON 的分類標記與欄位不變。

每輪採集完成兩秒後再採下一輪，同時最多一輪。採集在背景執行，刷新保留群組展開與選取；程序身分包含 PID 與啟動時間。程序消失或 PID 重用時退回仍存在的父層；若 `--from pid:…` 本身失效，保留舊資料並標示 STALE，不自動轉向新程序。

畫面只在資料、操作、視窗大小或秒數顯示改變時重畫。首次採集先顯示表格、工具列與 status bar，在列表中央顯示 `Loading resources...` 與約250ms更新的 spinner，完成後換成資源列並停止動畫；失敗時顯示錯誤，等待中仍可退出。Docker metadata 與用量每輪重新查詢，不使用跨輪快取。這不改變兩輪之間的等待時間。

退出會取消採樣等待與 Docker 查詢，回收自身建立的查詢程序，還原 terminal。取消是協作式的，已進入的原生系統／檔案查詢須先返回。此版本沒有停止服務、權限提升、歷史觀測或 Review 判定。
